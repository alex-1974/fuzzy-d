# Changelog

## 0.1.0 — 2026-11-04

The first public release of fuzzy-d. This release provides a documented,
consumer-oriented Type-1 fuzzy core with zero-order Sugeno inference.

- Added validated membership functions, linguistic hedges and selectable operators.
- Added editable, prepared, compile-time and multi-output evaluation paths.
- Added explicit missing-input/no-result behavior and diagnostic traces.
- Added public consumer facade, tutorials, independent consumer fixtures and
  DMD/LDC release qualification.

## Unreleased

- Initialized a standalone DUB library with an importable package root.
- Established a documented plan for editable, prepared, and compile-time inference paths.
- Added initial fast and release-gate CI definitions and an external consumer smoke test.
- Added the human-facing fluent facade with named sparse inputs.
- Added prepared numeric evaluation, worker-local prepared clones and caller-owned
  multi-output evaluation.
- Added the canonical thermostat consumer, conformance grid and Dunia-style
  benchmark proxy with preparation break-even and allocation measurements.
- Added DMD/LDC release qualification documentation and explicit No-Result
  semantics.
- Recorded the pre-0.1 public API freeze candidates and remaining compatibility
  decisions.
- Added the intended pre-0.1 to 0.1 migration boundary and compatibility notes.

No versioned release has been issued.
