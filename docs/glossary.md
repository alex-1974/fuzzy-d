# Glossary

**Membership degree:** degree in [0, 1] describing membership of a value in a fuzzy set; not a probability.

**Fuzzy set:** a set described by a membership function instead of a crisp boolean characteristic.

**Antecedent:** condition expression of a rule.

**Consequent:** conclusion/output associated with an activated rule.

**Prepared plan:** immutable, validated representation for repeated runtime inference.

**Compile-time specialization:** generating or selecting a specialized evaluation path from a model known at compile time.

**Unavailable input:** no observation is available; not synonymous with membership degree zero.
